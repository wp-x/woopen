# OpenList WoPan 目录读取对比与合并说明

核对日期：2026-10-10。

## 源码依据

- OpenList 默认分支快照：`482464c2affc5eeba5d4a25bb272aeb352ec5918`。
- 驱动：`drivers/wopan/driver.go`、`types.go`、`util.go`、`meta.go`。
- 上游源码：[OpenList WoPan](https://github.com/OpenListTeam/OpenList/tree/482464c2affc5eeba5d4a25bb272aeb352ec5918/drivers/wopan)。
- OpenList 使用 `wopan-sdk-go v0.1.5`；本项目使用 `v0.2.2`。
- 对比两版 `QueryAllFilesPersonal` 的参数构造，个人云请求相同。没有发现名称为“我的同步盘”的专门分支。

## 名称与空间

OpenList 的 `fileToObj` 原样保存接口返回的 `file.Name` 和 `file.Id`，单独保存 `file.Fid`。本项目也原样保留名称。

“我的同步盘”“同步盘”或自定义名称，都应按列表返回的目录名称展示，并使用目录 `id` 进入。名称不会决定 `spaceType`，也不能证明该目录属于家庭云。

OpenList 在 `FamilyID` 为空时查询个人云 `spaceType="0"`，不为空时查询家庭云 `spaceType="1"`。该配置控制家庭云，不是自动识别同步盘的机制。本项目继续使用个人云，没有因为目录名称切换空间或自动尝试其他空间。

## 择优结果

| 行为 | OpenList | 合并前的本项目 | 本次选择 |
| --- | --- | --- | --- |
| 目录名称 | 保留接口原值 | 保留接口原值 | 保留，不新增名称匹配 |
| WebDAV 目录分页 | 驱动逐页查询，每页 100 条 | 每页 200 条，少于 200 就结束 | 改用每页 100 条遍历 |
| 挂载根目录 | 使用配置的根目录 ID，默认 `0` | WebDAV 路径解析写死 `0` | 使用配置 `root_folder_id`，默认 `0` |
| 下载标识 | 使用 `FID` | 已修复为优先 `FID` | 保留本项目的修复及 URL 编码处理 |
| 并发目录查询 | 使用请求上下文 | 缓存、singleflight，但未传递列表请求上下文 | 保留缓存和去重，补充上下文传递 |
| 父目录映射 | 不把文件 `FID` 当父目录 ID | `FileInfo.ParentID` 错用 `fid` | 改为实际查询目录 ID |

按 200 条判断分页结束时，如果某账号的上游每页实际只返回 100 条，会在第一页停止。这是本次覆盖的可复现场景，不代表已证实故障账号存在该上游限制。

## 行为与配置

- WebDAV 从服务启动时配置的根目录 ID 开始查找。
- `root_folder_id` 未配置时使用 `0`；配置某账号的目录 ID 时使用该值。
- 调整根目录后需要重启服务，重建挂载文件系统及缓存。
- 上游某页失败时，返回带目录 ID 和页码的错误，不把已读取的部分列表作为成功结果。
- 未添加名称别名、家庭云切换、假数据或额外重试。

## 验证覆盖

- 同步目录位于第 101 个条目，继续读取第二页。
- 第一页恰好 100 条，读取下一页直到结束。
- “我的同步盘”“同步盘”和自定义目录名保持原样。
- 路径查询使用账号配置的根目录 ID。
- 管理 `id` 和下载 `fid` 分开保留。
- `parent_id` 对应查询目录，而非下载 `fid`。
- 上游列表请求继承调用上下文，取消及分页失败传播给调用方。

这些测试使用本地测试数据和测试 HTTP transport，不访问真实账号，也不能替代故障账号的实际挂载验证。
